It names things.

A port number tells you nothing. Quaydeck traces each listening socket back to the process, the project directory, the manifest and the git repository, so the row reads like something you recognise.

Finds what you forgot

The same project running twice on two ports. A server idle since Tuesday. A tsc --watch burning a core with nothing attached to it. Each one comes with the single button that fixes it.

Flags what you did not start

Anything listening from a path that is not a normal install location gets surfaced, and if it is bound to every interface rather than loopback, it goes to the top in red.

Brings them back

Projects you have run before stay in a list after they stop. One click reads the lockfile, picks the right package manager and starts the dev script in a terminal where you can watch it.

It reads a lot. It sends nothing.

A tool that inspects your processes should be specific about what it does with what it sees. Here is the whole ledger.

Reads, on your Mac

  • Listening TCP sockets, via lsof
  • Process command lines, uptime, CPU and memory, via ps
  • package.json and other project manifests, for names
  • Current git branch and whether it is dirty

Sends, off your Mac

  • Nothing.
  • No account, no analytics, no crash reporting
  • The only HTTP requests go to your own localhost ports, to read their title
  • Update checks are optional and can be turned off

Quaydeck is not sandboxed, because reading the process table and stopping a process it did not start are both forbidden inside the App Sandbox. That is also why it is not on the Mac App Store. It is signed with an Apple Developer ID, notarised by Apple, and the source is public, so you can check every one of these claims. Read the privacy note.

Install

Download the notarised build, or build it from source in about a minute.

Download the DMG

macOS 13 or later. Universal, so it runs natively on Apple Silicon and Intel. 

# or build it yourself
git clone https://github.com/quaydeck/quaydeck
cd quaydeck
./Scripts/build-app.sh --install

No Xcode project. Swift Package Manager and a shell script you can read.
