Quaydeck

Privacy

Last updated 27 July 2026

Quaydeck is a menu bar utility that shows which ports are listening on your Mac. This page describes exactly what it reads, what it stores and what it sends. It is short because the app does very little.

What Quaydeck sends

Two things, and nothing else.

  • HTTP GET requests to localhost on your own machine. For each dev server it finds, Quaydeck requests http://localhost:<port>/ to learn whether the server is answering, what status code it returns and what its page title is. These requests never leave your computer.
  • Update checks, if you leave them on. Quaydeck asks a feed for the current version number. This is an ordinary HTTPS request carrying no identifier for you or your machine beyond what any HTTP request carries. Switch it off in Settings.

There is no account, no sign-in, no analytics, no crash reporting, no usage statistics and no server belonging to Quaydeck that holds anything about you.

What Quaydeck reads

All of this stays on your Mac.

  • Listening TCP sockets, via lsof: port numbers, the process holding each one, and whether it is bound to loopback or to every interface.
  • Process details, via ps: process id, parent, command line, elapsed time, CPU and memory. The parent chain is walked to see whether a coding agent started a server.
  • Project files, for servers it can trace to a directory: package.json for the name and dependencies, and the presence of files like go.mod, Cargo.toml and Gemfile.
  • Git state, via git: the current branch and whether there are uncommitted changes to tracked files.

What Quaydeck stores

In UserDefaults, under app.quaydeck.Quaydeck, on your Mac only:

  • which projects you pinned
  • up to 30 recently-seen projects, with path, name, framework and last port, so they can be restarted after they stop
  • any project folders you added in Settings
  • whether notifications and automatic update checks are on
  • whether you have seen the welcome screen

Delete all of it with:

defaults delete app.quaydeck.Quaydeck

Permissions Quaydeck asks for

  • Notifications, only if you switch them on. Off by default.
  • Automation (Terminal), only when you use "Restart in Terminal". macOS asks the first time, and declining simply disables that one action.
  • Start at login, only if you tick the box. Quaydeck never registers itself.

Sandbox

Quaydeck is not sandboxed, because reading the system process table and stopping processes it did not start are both forbidden inside the App Sandbox. It is signed with an Apple Developer ID and notarised by Apple. The source is public, so you can read every system call it makes.
